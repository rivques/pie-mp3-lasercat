# pie-mp3-lasercat
Mini-Project 3 for Olin's Principles of Integrated Engineering. Robotic cat that chases a laser pointer. Project write-up is [here](https://docs.google.com/document/d/1wxBRSqR6WPOeRJawR11dYOMYs0kLAJtwNXfDsHEPv6Q/edit?usp=sharing).

To run: Upload the Arduino code (`./arduino_control`) to the Arduino, then, from the Raspberry Pi Zero 2 W, go into the `laser-tracker` directory and run `uv run main.py`.
